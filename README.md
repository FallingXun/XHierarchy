# XHierarchy
- XHierarchy 是一款用于 Unity hierarchy 插件工具，用于增强 Hierarchy 视窗的功能，主要有以下内容：
    - 优化层级显示表现。
    - 增加快捷编辑功能。
    - 增加自定义标签功能。
    - 增加快捷查找功能。
